Katze1
======
Motivation
----------
Because I was not good enough at the board game "Calico" by the German game publisher Ravensburger, I decided to write a bot in Java that would find the optimal moves. 

It took me a few days to get from developing the first concepts to having all the parts running, with different bots that follow different strategies. Although the weighting parameters slightly deviate from those in the game manual (and I did not find time to change them yet) I believe my best bot can compete with a good or very good human player (which I am not). 

I am especially proud of the project architecture because i succeeded quite well in separating the components (game logic, graphics, strategy) from each other and finding meaningful object-oriented abstractions.
